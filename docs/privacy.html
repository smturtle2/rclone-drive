개인정보처리방침

시행일: 2026년 11월 5일

이 방침은 smturtle2가 관리하는 개인용 rclone Drive 연결 프로젝트와 이 안내 사이트에 적용됩니다. 실제 파일 접근과 암호화는 사용자의 기기에서 실행하는 rclone이 수행합니다.

Google Drive 접근

rclone은 사용자가 Google OAuth로 승인한 권한으로 Google Drive API에 직접 접속합니다. 읽기·쓰기를 위해 Drive 파일의 목록과 메타데이터 조회, 다운로드, 업로드, 수정 및 삭제 권한을 사용할 수 있습니다.

선택한 폴더만 사용하도록 정하는 것은 rclone 설정입니다. 전체 Drive 읽기·쓰기 OAuth 권한이 해당 폴더로 한정되는 것은 아닙니다. 이 안내 사이트는 Google 로그인, 인증 코드 또는 토큰을 수신하거나 처리하지 않습니다.

인증 정보와 파일의 저장

OAuth 토큰과 암호화 설정은 사용자의 기기에서 관리합니다. 이 프로젝트는 파일이나 인증 정보를 수집하는 별도의 백엔드 서버를 운영하지 않으며, 사용자 데이터의 판매·광고 활용 또는 AI 모델 학습을 위한 수집을 하지 않습니다.

crypt를 거쳐 업로드한 파일 내용은 기기에서 암호화됩니다. 이름 암호화를 활성화하면 파일과 폴더 이름도 암호화됩니다. 암호화된 파일에도 크기, 개수, 수정 시각 등의 메타데이터는 남을 수 있습니다. crypt를 거치지 않은 업로드에는 이 암호화가 적용되지 않습니다.

복호화된 마운트와 로컬 읽기·쓰기 캐시에는 평문 데이터가 존재할 수 있습니다. 캐시의 보관과 정리는 사용자가 정한 rclone 설정을 따릅니다. 암호화 비밀번호와 선택한 추가 암호, 관련 설정은 사용자가 안전하게 보관해야 합니다.

연결 해제와 삭제

사용자는 Google 계정의 연결 관리에서 앱의 접근 권한을 취소할 수 있습니다. 기기에 저장된 인증 설정과 캐시는 별도로 관리해야 합니다. 권한 취소만으로 Drive에 보관한 파일이나 기기의 캐시가 삭제되지는 않습니다.

안내 사이트와 GitHub Pages

이 사이트에는 분석 도구, 외부 스크립트, 외부 글꼴, 입력 폼 또는 사이트 자체의 쿠키를 추가하지 않았습니다. 호스팅 제공자인 GitHub는 보안 목적으로 방문자의 IP 주소를 기록·보관합니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.

파일 저장과 OAuth 인증에는 Google의 서비스 및 개인정보처리방침이 적용됩니다. 자세한 내용은 Google 개인정보처리방침과 rclone crypt 공식 문서에서 확인할 수 있습니다.

문의와 변경 사항

사이트와 안내 내용에 관한 문의는 GitHub Issues를 이용할 수 있습니다. 게시물은 공개되므로 비밀번호, 토큰, 개인 파일 또는 인증 설정을 게시하지 마세요.

이 방침을 수정하면 이 페이지의 시행일과 공개 저장소의 변경 기록을 갱신합니다.
