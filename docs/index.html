Google Drive · 개인용 연결

내 기기에서 접근하고,
암호화해서 저장합니다.

개인 Google 계정의 Drive를 rclone으로 연결하기 위한 프로젝트입니다. 선택한 폴더를 마운트하고, rclone crypt를 통해 파일 내용과 이름을 암호화하는 구성을 안내합니다.

개인정보 처리 확인 ↗ GitHub 저장소 ↗
01

내 계정으로 인증

사용자가 자신의 기기에서 Google OAuth로 권한을 부여합니다. 이 웹사이트에는 로그인이나 인증 코드 입력 기능이 없습니다.

02

업로드 전에 암호화

crypt 마운트를 거친 파일은 기기에서 암호화된 뒤 Drive로 전송됩니다. 파일과 폴더 이름의 암호화도 설정할 수 있습니다.

03

필요할 때 로컬 접근

파일을 열 때 필요한 데이터를 내려받아 복호화합니다. 읽기·쓰기용 로컬 캐시의 크기와 정리 조건은 rclone 설정으로 관리합니다.

이 페이지의 역할

이 사이트는 개인용 OAuth 앱의 목적과 개인정보 처리 방식을 설명하는 정적 안내 페이지입니다. Drive 파일을 보관하거나 인증 토큰을 받는 서버가 아니며, rclone 또는 Google의 공식 서비스가 아닙니다.

사용자가 선택한 폴더는 rclone 설정으로 정합니다. Google OAuth의 Drive 읽기·쓰기 권한 자체가 그 폴더에만 제한되는 것은 아닙니다.
